# Synapse AI - AI Study Assistant Frontend

Interactive React + Vite frontend for **Synapse AI**, featuring:
- **Planner Tab**: Smart study scheduler, tasks list, retention analytics & subject mastery progress.
- **Solver Tab**: Gemini-powered AI academic doubt solver with LaTeX formula rendering and diagram visualizations.
- **Notes & Quiz Tab**: Neural Knowledge Forge document uploader (PDF/TXT/EPUB), extracted concise summaries, flashcard deck, and dynamic quizzes.
- **Profile Tab**: Zero-Knowledge sandbox, JWT active session card, Edu domain verification, and security isolation metrics.

## Setup & Running
1. Install dependencies: `npm install`
2. Start development server: `npm run dev` (Runs on http://localhost:3000)
3. Connects to backend on http://localhost:5000
